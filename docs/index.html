📋 Scientific Design Guide

Validated design rules from peer-reviewed literature.

⫿ IDE

Use: Amperometric/impedimetric biosensors

  • Finger width: 0.1–2mm (screen print)
  • Gap: ≤ finger width for redox cycling
  • Pairs: 10–50 for adequate signal
  • Metallization ratio: 0.5 optimal

Ref: Kosri et al., Nanomaterials 2022

◉ Three-Electrode

Use: CV, EIS, battery testing

  • WE: 1–6mm (3mm standard)
  • CE: ≥ 10× WE area
  • RE: 1–3mm Ag/AgCl
  • Spacing: 2–5mm

Ref: Ossila Electrode Guide

◎ Ring-Disk

Use: Generator-collector, ORR

  • Disk: 3–6mm (5mm standard)
  • Gap: 375μm industry standard
  • Ring: 1–2mm width
  • N: ≈ 0.256 collection eff.

Ref: Pine Research RRDE

⌇ Serpentine

Use: Stretchable/wearable electronics

  • Trace: 0.5–1mm
  • L/H ratio: 1.5–3:1
  • Meander amp: ≤ seg_h/2

Ref: Suhaimi et al., 2022
